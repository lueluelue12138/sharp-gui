# 图库与模型原片联动

## 使用方式

- 相册中的图片或视频有模型时，卡片左上角显示蓝色 **3D** 标识；多个模型显示数量。排队、重建中和失败另有状态提示，已有模型仍可打开。
- 打开原片预览，右上角 **查看 3D** 是主要入口，旁边的「全部模型」按钮始终可查看关联结果。下载和关闭继续使用现有按钮。
- 只有一个可用结果时直接打开；多个结果且未设默认时打开「关联模型」面板，显示封面、名称、时间、重建/编辑副本和可用的质量档位。
- 本机用户点击星标设定默认模型，再次点击取消。设置默认后，「查看 3D」直接打开默认模型；其他版本仍保留在面板中。
- 再次生成放在关联模型面板底部。图片加入现有队列，视频打开原有重建设置弹窗。没有关联模型的原片继续使用原来的生成入口。
- 从图库打开模型后，「返回图库」保留当前相册、筛选、已加载媒体和滚动位置。

## 固定相册「模型原片」

此相册固定在配置相册之前，不对应新的实体目录，也不需要手动扫描。它汇总生成模型对应的图片和视频；文件内容相同的来源只显示一次，文件名相同而内容不同的来源分别显示。没有来源资料的纯导入模型不包含在内。

缩略图优先复用同一来源在普通相册里已经生成的图片缩略图（480 像素宽）或视频 poster（640 像素宽）。既支持明确相册引用，也支持后台完成的相同内容关联；只读取对应版本的已有缓存，不重新打开原片、抽视频帧或另外生成缩略图。没有现成缓存时保留原模型封面。相册原盘离线时，已验证的本地缩略图缓存仍可显示。

删除普通相册会按既有规则清理该相册缓存，「模型原片」随即回退到模型自己保存的封面，不依赖已删除的相册。历史单图模型缺失或为空的媒体类型按图片读取；类型判断同时用于缩略图、原图预览、照片计数和筛选，不改写来源内容身份或模型文件。

同一模型的 PLY / SPZ 等伴随格式计为一个模型。多次生成、保存编辑副本会增加数量；覆盖原模型不会增加数量。编辑副本继承原片关联，即使原模型随后删除，副本仍可以预览原片。删除最后一个模型后，该来源从「模型原片」移除，不删除用户相册里的原文件。

任务完成、编辑保存和删除触发关联刷新。系统相册的来源数量和各卡片的模型数量使用完整资产索引，不依赖模型资产库当前加载的分页或筛选。

## 原片缺失与历史恢复

原片不可用时，已有模型仍可打开。单图生成保存的输入副本可用时仍可预览；视频继续引用已有上传缓存或相册文件，这个功能不会额外复制一份视频。发现原片不可用后禁用再次生成；重新接入磁盘并成功打开原片后恢复可用状态。

第一次进入图库时，会在后台逐批补齐历史来源。模型已有明确原片引用或保存的原图副本时，可以确认来源；相册索引中的候选文件通过相同内容校验恢复关联。恢复期间显示提示，关联标识可能逐步出现。没有可靠资料的结果保持未关联，不按文件名相似程度猜测。

恢复使用已有相册索引，不遍历额外目录；每轮最多处理 32 个历史模型和 256 个候选媒体。缺失磁盘或暂时失败的候选至少间隔 5 分钟再尝试，普通列表不会重复读取完整原片做校验。

后台补齐来源保留模型元数据的修改时间，不把维护操作当作用户修改。模型资产库默认和侧栏「近期模型」均按「最近创建」降序，最新结果在上；资产库仍可手动选择「最近修改」、名称或大小。

同一路径上的原片被替换后，重新扫描相册或访问原片会更新文件版本；当前文件不会继续继承不同内容的旧模型。旧模型对应的来源在「模型原片」中独立保留。文件名或路径的重命名不作为内容身份判断依据。

## 实现与接口

- 新任务使用流式 SHA-256 记录来源内容身份，sidecar 保存安全的来源名称、媒体类型、文件版本和媒体元数据；编辑保存沿用这份资料。
- 模型资产索引版本为 4，增量 catalog 保存来源摘要；默认选择在同一索引的 `source_defaults` 中原子写入并复用索引锁。没有引入数据库或另一份资产真相源。
- 系统相册 ID 为 `model-sources`。原片访问复用受控图片/视频解析、Range、权限检查和已有播放签名。响应不暴露服务器绝对路径。
- 暖列表和关联查询只读 catalog，不扫描媒体目录、不同步计算来源内容哈希。分页保留快照，创建时间、修改时间、名称、大小排序以及图片/视频筛选沿用普通相册约定。
- 前端对模型修订与任务状态独立订阅，并丢弃相册/预览上下文已变更的迟到响应。

| 接口 | 功能 | 权限 |
| --- | --- | --- |
| `POST /api/photo-models` | 批量来源关联摘要，每次最多 200 个媒体 ID | 已解锁 |
| `GET /api/photo-models/<media_id>` | 完整关联模型、默认结果及最近确认的原片可用状态 | 已解锁 |
| `POST /api/model-sources/<source_id>/default` | 设置或取消默认模型 | 本机 owner |
| `GET /api/photo-albums/model-sources/photos` | 系统相册分页，复用现有图片/视频类型筛选 | 已解锁 |

## 验证范围

后端针对来源重复、同名异内容、同路径替换、编辑副本/覆盖、源模型删除、默认选择、离线与重新接入、历史恢复、受控视频 Range、权限和暖查询性能做回归。前端完成类型/代码检查、任务及编辑/朝向测试和生产构建。

缩略图回归包含历史来源类型为空、删除原相册后的最终图片响应、缓存复用和无重复生成；校验实际封面字节、原图预览，以及「全部 = 照片 + 视频」计数和筛选。

隔离工作区的浏览器检查覆盖系统相册、单结果直接打开、多结果选择、默认星标、返回图库、任务完成后的自动关联、桌面与窄屏、中英文和实际玻璃面板。队列完成使用测试模型模拟；本次不重新运行 ML-Sharp 或视频训练，也不改变模型几何、导出坐标及编辑算法。
