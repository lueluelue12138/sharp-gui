# 高斯模型编辑器

可以从模型资产库的卡片快捷按钮或右侧详情操作中的「编辑模型」直接进入，也可以打开模型后点击底部的「编辑模型」。编辑入口仅对本机 owner 显示。资产库根据实际编辑源的文件头禁用不支持的模型；查看器验证完整编辑源后才显示入口。点击详情标题旁的「编辑」仍用于修改名称、标签和备注。

### 支持范围

- 编辑器支持只有 `vertex` 元素的标准高斯 PLY（SH0–SH3，ASCII / 大小端二进制）、支持版本的 SPZ 和固定记录长度的 SPLAT；同时受文件大小和点数上限约束。RAD、普通点云或不符合高斯属性结构的文件不能编辑。
- 当前 ml-sharp 单图导出的原始 PLY 除高斯点，还包含 `extrinsic`、`intrinsic`、`image_size`、`frame`、`disparity`、`color_space` 和 `version` 元素，当前编辑保存流程不支持同步这些数据。因此禁用资产库编辑按钮，隐藏查看器编辑入口，保留正常预览、下载和资料编辑。
- 判断依据是文件结构，不是「生成」或「视频」标签。标准高斯 PLY 即使来自图片仍可编辑；导入的 ml-sharp 原始 PLY 仍不可编辑。同一资产有 PLY 和 SPZ 时，遵循编辑器现有的 PLY 优先级，不自动绕过原始 PLY 改用 SPZ。
- 本次不会转换或重写原模型，也不会丢弃相机元素以强行启用编辑。独立 SPZ 只能根据该文件实际保留的数据判断；无法从缺失的 PLY 元数据还原其原始结构。

界面沿用项目的玻璃面板、系统字体、蓝色强调色和浅色 / 深色主题。资产库卡片、近期模型侧栏与详情中的名称、格式和大小使用统一毛玻璃悬浮提示，长名称截断后仍可查看完整信息；卡片和侧栏的主打开按钮也提供键盘聚焦提示。

## 使用

- **设置原点**：拖动坐标轴中心，或输入原点三轴位置，只改变原点和网格位置，模型及观察相机保持不动。所有模型进入编辑器时都显示文件真实零点，旋转手柄使用同一个原点；观察中心与初始球形 / 盒形选区中心可以位于别处。点击「原点移到观察中心」可重新定位，支持撤销。保存时把选定点写成实际模型坐标 `(0,0,0)`。
- **旋转**：绕选定原点拖动圆环或输入角度，使模型对齐经过原点的水平网格和世界坐标轴。面板只显示旋转，进入编辑器时计为 0°，既有模型朝向作为基准。输入时实时预览，聚焦数值后可用滚轮微调，Shift 降低步长；失焦或滚轮停止时合并一次撤销。
- **重置朝向**：在旋转面板恢复进入编辑器时的模型朝向，保留选定原点、删除的点和观察视角；可以撤销。若旋转期间重新选过原点，重置绕新的原点恢复朝向，不保证回到原来的空间位置。
- **矩形选择**：左键拖动框选；Shift 添加，Ctrl / Command 移除。默认按投影椭圆与框的相交范围判断，中心在框外的毛边也可以选中；包含所有深度的点。也可切换按中心或完全包含。
- **拖动数值**：数值旁的双向箭头可左右拖动，右增左减；按住 Shift 精细调整。保留数字输入与聚焦后滚轮微调；手柄聚焦后也可用左右方向键。每次拖动松手只产生一步撤销。
- **球形 / 盒形选择**：坐标轴移动选区中心。球形可拖动面向观察相机的外圈任意位置或蓝色双向箭头调整半径；盒形可拖动六个面的双向箭头或轮廓边线调整对应面，对面保持固定，中心和尺寸同时更新。箭头沿调整方向显示，屏幕大小不随缩放改变，仅显示符号，无边框底座，保留悬停高亮及扩大的命中范围。接近朝向观察相机的深度轴箭头会隐藏，切到侧视 / 顶视或转动视角再调整。Shift 精细调整，金色高亮实时更新；支持一步撤销 / 重做选区位置及尺寸。仅改变选区不算模型未保存修改。
- **删除选中 / 仅保留选中**：立即预览结果。Delete / Backspace 删除；Esc 取消选择。
- **撤销 / 重做**：按钮、Ctrl / Command Z、Ctrl / Command Shift Z 或 Ctrl Y。历史最多 40 步，位图内存最多约 32 MiB；超大模型会缩短历史。
- **初始相机**：调整视角后点击「将当前视角设为初始视角」。未主动设置时沿用进入编辑器时的视角。正视、侧视、顶视和初始视角按钮只改变观察视角。
- **保存为新模型**：创建独立 PLY 和 SPZ 资产，自动生成封面并打开新模型。源文件不被覆盖。后续下载和分享使用实际编辑后的文件。
- **覆盖原模型**：点击保存按钮旁的箭头选择，确认后更新当前资产，保留编号、创建时间、来源、标签和备注。名称默认沿用原模型，可手动修改。生成模型同时更新 PLY / SPZ，并移除已过期的其他模型格式；导入模型保持原格式，只修改项目管理的导入文件，不修改导入前的用户原文件。覆盖成功后重新加载模型并重置已烘焙的预览变换。退出保存后无法通过编辑器撤销覆盖。
- 保存后近期模型自动刷新，即使资产总数大于已加载的分页条目数。保留原视频关联、重建报告、标签和备注；单图模型的原图预览也随副本保留。上传视频由所有关联副本共享，最后一个引用删除后才清理缓存。

退出编辑时会提示丢弃未保存的调整。手机窄屏通过右侧参数按钮展开检查器，建议用鼠标进行精确清理。

## 技术实现

参考 [OOOSplat](https://github.com/ooolabdev/ooosplat) 的编辑流程；对比源码版本为 `032a58252a7a302c2684c21ac3694a64d6fcbf32`（Apache-2.0，复查其 0.6.0 主线）。参考其位图删除、选择高亮、有限历史、编辑坐标与 PLY 坐标分离、保存时处理球谐方向的思路。Sharp GUI 使用现有 Three.js / Spark 渲染链路，独立实现选择及 NumPy 球谐旋转，未引入 PlayCanvas，也未复制界面和品牌资源。

- 编辑使用非 LoD 的完整点集，与后端源文件顺序保持一致。优先使用伴随 PLY，避免从已量化的 SPZ 反复编辑。
- CPU 分块计算矩形投影椭圆 / 世界坐标体积选区；每块让出执行权。椭圆取自尺度、四元数和透明度对应的可见范围；三维选区使用保守包围范围，相交可能包含靠近角落的额外高斯，完全包含可能排除部分边界高斯。选中与删除分别使用按位存储的位图。
- 参数及手柄移动按帧调度区域选择，取消旧计算并拒绝过期结果。选择计算期间禁止保存、删除，但数值输入和手柄保持可用。
- 矩形拖动预览每帧最多更新一次，使用已计算的坐标快照；松手、取消和关闭时清除待处理更新，避免延迟渲染读取已释放的拖动起点。选择失败会显示可恢复的提示。
- Spark `objectModifier` 读取 RGBA8 状态纹理，高亮选中点、将删除点的透明度置零，保留正常的视角相关颜色。
- 原点独立存储于世界坐标，移动手柄不修改模型矩阵。数字和圆环统一应用 `T(origin) × R(next) × R(previous)⁻¹ × T(-origin)`，绕同一个原点旋转；校准旋转与进入编辑器时的预览修正分离。
- 打开编辑器时，原点手柄始终位于模型矩阵变换后的文件 `(0,0,0)`，不读取“新旧模型”标记、不以相机目标推测原点。观察中心用于取景/轨道相机，选区中心用于裁剪，两者均可与真实零点不同。
- “原点移到观察中心”是用户主动执行的可撤销操作；只移动待保存原点，模型和相机不动。保存前不改写原文件。
- 历史同时记录模型矩阵、原点、校准旋转、删除位图和初始相机。保存矩阵为 `B⁻¹ × T(-origin) × modelWorld`；`B` 是普通 PLY 的既有显示基底（X 轴 180°、显示倍率 2）。这是 OOOSplat `engine_transform_to_ply` 同样使用的坐标换算方式；具体基底由渲染器决定，不能直接照搬 PlayCanvas 的 Z 轴 180°。
- 相机位置/目标也通过 `B⁻¹ × T(-origin)` 换算到文件空间，上方向应用同一个旋转。不把显示倍率写入模型尺寸；不需要额外的单位 `viewer_transform` 才能重开。覆盖保存时清除当前模型已烘焙的临时显示变换，恢复普通显示基底。
- 视频生成通过相机上方向调平，并估计观察中心作为取景提示；COLMAP / Brush 文件零点不保证落在主体上。这是坐标原点与取景中心的区别，不是模型生成时间的区别。校准保存将选定点实际写为零点，并把朝向烘焙到坐标、高斯旋转和 SH 中。
- 后端分块过滤 PLY，处理位置、对数尺度、旋转四元数、可选法线及 SH0–SH3；球谐矩阵通过标准实球谐基函数独立求解。
- 导出使用普通 PLY 坐标；`viewer_transform=null`，不靠本项目的旁附记录纠正几何。`viewer_camera` 仅用于恢复取景，删除这些记录仍保留校准后的几何、真实零点及尺度。不同软件的默认观察相机、背景、色调和坐标显示约定可能不同，不能保证初次打开的截图完全相同。
- SPZ 保留 SH0–SH3，仍有格式本身的量化；大幅平移时降低位置小数位数，避免坐标截断。

## API 与边界

| 接口 | 功能 | 权限 |
| --- | --- | --- |
| `GET /api/model-assets/<id>/editor` | 返回格式、完整点数、源修订标识和受控源地址 | 已解锁 |
| `GET /api/model-assets/<id>/editor/source` | 完整模型，支持 Range；`v` 参数验证源修订 | 已解锁 |
| `POST /api/model-assets/<id>/editor` | 按删除位图和世界矩阵保存；`save_mode=copy`（默认）创建副本，`save_mode=overwrite` 覆盖原资产 | 本机 owner |

支持标准高斯 PLY、SPZ v2 / v3、32 字节 SPLAT；暂不支持只有 RAD 的资产。PLY 必须含标准浮点高斯属性，不接受普通点云、列表属性或其他元素。上限 800 万点、2 GB 源文件、2 MB 编辑请求。变换只接受正向等比缩放和旋转，不接受镜像、剪切或非等比缩放。

删除及完全包含仍以整颗高斯为单位，不对单颗高斯做局部切割，也不承诺任意视角下得到严格平面切口。标准高斯 PLY/SPZ 没有用于存储任意局部切割面的字段。OOOSplat 对照版本的矩形选择和球/盒裁剪同样判断高斯中心，并整体隐藏高斯，而不是切割其局部。

保存校验修订标识、点数、位图长度与尾部填充位、相机和矩阵，拒绝空模型；受控路径检查复用资产服务。一次只执行一个保存任务，转换失败时清理新文件。错误响应使用固定信息，详细诊断只在本机日志中。

覆盖在受控目录的隐藏暂存文件夹中完成转换，发布前再次检查源文件修订，并在 Windows 上释放 PLY 文件映射。替换期间保留旧文件备份；替换或索引写入失败时恢复旧文件。成功后清理备份，不永久保存历史版本；该恢复机制针对正常请求失败，不提供进程异常退出或断电后的事务恢复。文件地址附带持久化修订号，避免同编号模型命中旧缓存。

## 验证

- `venv/Scripts/python.exe -m pytest -q`：后端路由、权限、输入、原文件保护、失败清理、端序、SH 方向、SPZ 解码和大范围平移。
- `npm --prefix frontend run test:model-editor`：位图索引、屏幕投影裁剪、世界坐标体积、添加 / 移除和取消。
- 框选稳定性回归覆盖百万点位图、分块让出执行权、待处理拖动预览取消，以及 784,853 点模型连续 15 次框选 431,498 点、删除 / 撤销和球形 / 盒形选择。旧版黑屏在本机自动操作中尚未复现，修复依据是延迟更新读取已清空起点的确定性风险。
- `npm --prefix frontend run test:viewer-orientation`：相机和模型描述符回归。
- 浏览器实测 784,853 点 SH3 模型：矩形高亮 / 删除 / 撤销 / 重做、体积选区、手柄 / 数字变换、相机记录、保存和重新打开。测试副本裁剪后为 226,985 点，源文件 SHA256 保持不变。

手机验证为浏览器 375 × 812 视口检查，尚未覆盖真实触控设备和所有浏览器。
