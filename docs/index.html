视频 3DGS 重建

从视频重建
可漫游 3D 场景

用环绕拍摄的视频重建物品或场景。固定源帧规划、COLMAP 相机配准和 Brush 训练，让连续画面汇成有细节、有层次的静态 3D 模型。

  • 细节优先的质量档高质量保留 1920 长边；极致档在 12 GB 预算下保留 3840 长边。
  • 每一步，都看得见从抽帧、配准到训练，阶段进度与配准检查清晰呈现，训练中可预览。
  • 让结果继续创作输出 PLY / SPZ，进入资产库编辑、导出动画，也能回看原视频。

模型编辑

核心特性

Apple 风格设计

通透的玻璃质感、清晰的层次与自然的动效，深浅主题与中英文界面保持一致。

本地创作，安心访问

推理与模型保存在本机；局域网访问支持密码门禁，远程设备浏览作品，本机保留管理权限。

高性能渲染

Three.js + Spark 2.0 驱动交互预览，支持 PLY、SPZ、SPLAT、RAD，按模型与设备选择渲染效果。

全模态控制

不仅支持键盘 WASD 漫游，更支持移动端陀螺仪体感操控，身临其境。

移动端虚拟摇杆

触摸屏设备内置虚拟摇杆，实现如PC端键盘一样的漫游体验。

设置，各归其位

查看器、图库、视频与安全按用途分组。全局配置记住工作区与相册，换新版完整包也能接续使用。

在界面中管理版本

受支持的 Git 安装与受管便携包可在更新中心选择稳定版或最新代码，保留模型、配置与运行环境。

作品，有序收藏

生成、视频和导入模型统一管理，支持排序筛选、详情与元数据查看，以及直接进入编辑。

独立 HTML 分享

一键导出，
让作品自由流动

把生成的模型与查看器封装成一个 HTML 文件。无需另建服务，发送文件后即可在支持 WebGL2 的浏览器中离线打开。

  • 一个文件，完整作品 内嵌模型、查看器与依赖，使用 SPZ 压缩保存模型
  • 打开，就是你选好的角度 保留初始视角，支持全模型取景、重置与环绕播放
  • 把探索，也交给观众 背景切换、全屏、双语帮助与移动端触摸控制

即刻开始，留住空间。

Windows 原生运行，也支持 macOS 与 Linux 源码安装。

Windows 完整便携包

内置运行环境与模型缓存，解压后启动。按显卡选择 RTX 50 或主流 NVIDIA 包；视频重建请选择 RTX 50 视频完整包。

前往下载与校验 Release 提供网盘入口与 SHA256 校验。

从源码，掌控部署

克隆仓库并运行安装脚本。单图推理按设备使用 CUDA、MPS 或 CPU；视频重建另需 COLMAP、Brush 与 FFmpeg。

./install.sh
