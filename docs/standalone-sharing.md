# 独立 HTML 分享查看器

## 使用

在生成模型的查看器或模型资产库中选择导出，获得单个 `_share.html` 文件。文件内包含查看器脚本、样式和模型数据；不包含原图、原视频、本机工作区路径或访问码。不增加公开托管服务，也不改变外部导入/临时资产暂不支持旧导出的限制。

新文件提供初始视角、全模型、自动环绕、背景切换、全屏及中英文操作指南。左键/单指旋转，右键/双指平移，滚轮/双指缩放；点击模型设置观察中心，WASD/QE 移动，Shift 加速，Alt 精调，R 回初始视角。移动设备或窄屏可打开移动圆盘。

分享者对内容负责。接收者拥有 HTML 中的模型数据，可以提取模型；原应用中的访问码、删除、撤销会话不会收回已经发出的文件。

## 视角与画质

- 使用主查看器同一套默认展示变换和来源方向规则，只改变显示方式，不改写嵌入模型的二进制或文件原点。
- 有有效 `viewer_camera` 时恢复保存相机，包括相机 up 与竖屏视场修正；编辑后的保存结果遵守其明确的 `viewer_orientation`。
- 无相机的视频模型按包围盒取景；单图模型保留主查看器近景与焦点语义。任何模型都能显式选择全模型取景，再旋转/缩放观察。
- 初始/全模型模式会随窗口尺寸重新取景；手动操作后保留观察位置。全模型可能包含远处残留高斯，主体显得较小，此时可点击主体聚焦或使用已保存初始视角。
- 默认保留完整模型、不构建新的 LoD 树、不自动降低点数；原模型本身未重建的区域仍可能有空洞，环绕不会补出缺失内容。单文件 RAD 依赖已安装 Spark 的解码能力；外部分页资源不在一个 HTML 中，不能声称支持该类外部资源离线分享。

## 构建与部署

继续使用项目已安装的 Three.js 0.180.0 / Spark 2.0.0。官方 SplatMesh 支持 `fileBytes`、包围盒与 Three.js 相机控制；当前问题来自旧模板固定取景，而非引擎版本。

`npm run build` 的 Vite 插件会同时生成 `frontend/dist/share/share-viewer.js`、`share-viewer.css`、`LICENSES.txt`。独立入口为 `frontend/src/share`，复用通用 Button、lucide 图标、CSS Module、设计 Token，以及方向/相机工具。不在运行时访问 node_modules 或 CDN；完整包和代码更新需要同步携带 dist。

后端 `/api/export/<id>` 继续保留权限、格式回退、UTF-8 文件名和体积响应头，只嵌入归一化预览白名单。JSON/名称安全转义，模板单次替换防止名称中的占位符被再次解释。缺少构建产物返回 503 `share_viewer_unavailable`，且不会先转换模型；重新构建前端即可恢复。

## 验证与限制（2026-10-20）

- 后端格式、白名单、注入、缺构建、权限专项与既有回归；前端取景测试覆盖宽/竖屏、相机方向/roll、深度与非法包围盒。
- 本机 HTTP 下真实 SPZ 单图（1,179,648 点）、视频（271,286 点）与保存了相机的编辑结果（89,505 点）均实际渲染；可控 PLY、损坏数据与重试清理通过。
- 桌面重置、全模型、环绕、全屏、背景、帮助与移动圆盘；390/320px 英文无水平溢出。指针模拟不是触屏实机验证；浅色尚未切系统主题实测。
- **本地文件手工验收通过（2026-10-20）：** 用户双击生成的独立 HTML 后确认“能打开，模型和操作正常”。这是用户本机人工验收；自动化工具仍禁止 `file://`，未绕过策略。
- 单个 HTML 无法避免大模型的 base64 体积、浏览器内存与 GPU 容量限制。解码会分块让出主线程，已读 DOM 数据释放，错误给出文本和重试；资源不足仍可能需要更强设备。

官方参考：[SplatMesh](https://sparkjs.dev/docs/splat-mesh/)、[相机控制](https://sparkjs.dev/docs/controls/)。
