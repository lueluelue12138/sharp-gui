# 外部模型预览与编辑

2026-10-21 更新。本项先在 `bb0a4cf` 完成只读核查，随后按用户确认修改默认预览；下文描述当前实现。

## 默认打开效果

| 文件或资产 | 预览分支 | 取景与编辑 |
| --- | --- | --- |
| 普通外部 PLY / SPZ / SPLAT / RAD | 与视频模型一致，`y-front` | 围绕包围盒中心取景；标准高斯 PLY、支持版本的 SPZ / SPLAT 可编辑，RAD 不可编辑 |
| 原版 ml-sharp PLY 的完整八元素结构 | 单图分支，`default` | 沿用单图模型取景；额外相机元素暂不支持编辑 |
| 已保存明确校准的导入资产 | 资产自己的预览朝向 | 保存相机、显示变换及浏览器内该资产的预览设置继续生效 |
| 项目内生成的单图 / 视频模型 | 继续按各自已知来源与明确提示 | 不受未知外部模型默认值影响 |

普通导入只采用视频预览方式，**不会把来源伪造为视频**；仍显示在「导入」类别，未知原片保持为空。这同时覆盖资产库导入和主页面单文件临时预览。

已有导入记录若没有明确朝向或来源，也使用新规则。索引版本升级时重建可派生的列表摘要，保留资产身份、名称、标签、封面、资料和已保存校准；热列表不反复扫描模型头部。

## 单图识别的范围

只读取 PLY 开头至多 512 KiB，核对高斯属性，以及上游 save_ply 的完整结构：vertex、extrinsic(16)、intrinsic(9)、image_size(2)、frame(2)、disparity(2)、color_space(1)、version(3)，包括对应标量类型。

- 匹配表示兼容当前 ml-sharp 原版导出结构，可以使用单图预览；不是对文件作者的认证。
- 缺项、不同字段类型、只有相机字段、注释或文件名中含有 ml-sharp，都不作为识别依据。
- SPZ / SPLAT，以及经第三方转换而丢失附加元素的 PLY，没有可靠来源标志，采用通用默认值。
- 不根据模型扁平程度、包围盒大小、名称或预览外观推测来源。识别失败不会阻止正常导入。

## 编辑入口与文件坐标

主页面单文件预览仍是临时本地文件。「加入资产库」只导入；「加入并编辑」先导入受控副本，再根据后端实际文件检查进入编辑器。临时对象地址在替换、关闭和导入成功时释放。资产库卡片、详情与查看器继续提供编辑入口，编辑权限仍仅限本机所有者。

支持标准高斯 PLY（只有 vertex 元素，SH0–SH3）、支持版本的 SPZ 和 SPLAT。原版 ml-sharp PLY 的附加相机数据暂不能随编辑同步，所以不提供编辑入口，也不通过改用伴随 SPZ 或丢弃元素来绕过限制。详见[模型编辑说明](model-editor.md)。

导入不会重写模型。默认 X 轴 180° / 2 倍显示基准及视频分支的额外朝向修正仅影响预览；编辑保存才会把实际变换、所选原点、点删除和高斯方向写入模型文件。另存副本保留源文件，覆盖仅替换受控资产内的副本，不修改用户选择的外部原文件。

## 实际限制

- 文件本身并不一定含有可恢复的原项目初始相机；按包围盒取景也可能受远处残留点影响。
- 外部工具采用不同坐标基准时，同一文件的首次观察方向仍可能不同。预览正常不代表已完成调平；需要时在编辑器校准后保存。
- 单独重新导入已下载文件，会创建新资产，不会自动带回旧资产的 sidecar、相机、标签或浏览器覆盖设置。
- 正面视角开关沿用当前状态；外部导入不会自动切换为无限制环绕。
