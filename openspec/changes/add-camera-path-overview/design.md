## Context

镜头动画使用主查看器相机逐帧采样；从相机自身视角看不清相机轨迹。需要独立观察相机，同时保证记录、播放与导出的相机保持真实值。

## Goals / Non-Goals

**Goals:** 模型与轨迹同空间展示、编号关键帧、视锥角度、当前相机同步、自由观察和重新取景，中英及窄屏适配。

**Non-Goals:** 拖动轨迹编辑镜头、修改模型/原点、把辅助线写进视频、增加第二份模型或 WebGL 上下文。

## Decisions

- 使用独立 PerspectiveCamera + OrbitControls，只切换渲染观察相机；记录与播放仍使用原相机。Why：避免把观察动作误写成关键帧。备选在原相机上显示路径无法看到自身位置；复制模型增加显存。
- 路径调用现有实际动画采样器，关键帧绘制编号和视锥，白色标记同步原相机。Why：曲线与导出一致；不以折线冒充平滑路径。视锥长度为示意比例，角度、方向及画幅按实际相机计算，不表示远裁剪距离。
- 辅助物全部置于专用 Three 层，仅观察相机启用；视频与镜头缩略图继续用原相机，天然排除辅助物。退出/重建时销毁几何、材质、标签纹理与控制器。

## Risks / Trade-offs

- [重叠镜头/极端距离] -> 保留真实坐标并提示同位置镜头可重叠；列表仍可定位选择；提供重新取景。
- [观察时误记录] -> 总览模式禁用记录/替换，并给出返回镜头预览的提示。
- [导出污染与生命周期] -> 专用层隔离并验证实际视频；不更改原相机层掩码，清理后恢复控制，数据变化只重建辅助物不重置观察视角。
- [复杂模型性能] -> 沿用一个 renderer/模型，最多约2048采样点和100个视锥；无额外模型下载。

## Migration Plan

无数据迁移，无项目 JSON 结构变化；回退源码与同批 dist 即可。
