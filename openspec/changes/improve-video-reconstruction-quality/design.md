## Context

已完整读取上游 0.5.0、0.6.0、0.6.1、0.7.0 发布说明。固定 0.7.0 标签 e2af865 使用 OOOBrush ooo-v1.0.0（866a7d65），而本项目使用官方 Brush 0.3.0。新旧梯度阈值不具备可直接互换的数值口径。上游中档为 8 FPS、1920 工作长边、1600 SfM 长边、8192 特征、15000 步、100 万点上限、0.002/0.12/13000 增密配方。

## Goals / Non-Goals

**Goals:** 采用固定、可校验且可以实际运行的新训练引擎与匹配配方；在标准模型文件中保留质量收益；测量完整运行耗时并给资产详情提供可读摘要；检查显示排序与训练缺陷的区别。

**Non-Goals:** 不移植全景、补拍、遥测或整个上游应用；不强制自动删点来掩盖漂浮物；不修改用户原素材、原模型或 ml-sharp；不承诺所有素材的相同画质提升。

## Decisions

1. 固定 OOOBrush 1.0.0 及其发布哈希，使用独立版本目录和新的 CLI 契约，保留来源和完整许可。Why：新的训练实现包含导出时烘焙的尺度滤波、非有限值处理及不同的优化策略；只复制数字到旧引擎不可靠。备选是保留旧引擎微调；不足以对照上游当前效果。便携 runtime revision 递增，拒绝旧包直接代码升级。
2. 以其普通视频配方为依据，按档位限制点数与增密阶段，完整保留 SH；中档维持 1920 和 15000 步。Why：限制不必要的点增长，同时保留最终收敛时间。备选是增加训练步数/点数，会增加成本且不能保证消除杂物。
3. 保留当前已验证的 COLMAP，不顺带引入 CUDA 13.2 的新平台门槛；只在现有命令能力内增强跨时间匹配，并明确记录实际策略。Why：训练引擎和 COLMAP 是不同变量，需要分开验收。备选是整套替换上游运行时，验证面过大。
4. 重建耗时以任务实际开始至结果生成完成计，不含排队；阶段使用单调时钟，UTC 时间仅用于标注。持久化生成摘要版本、引擎、耗时、输入规格、训练配置、配准统计和点数。历史缺失显示未记录；编辑派生资产沿用原始生成来源，注明不是编辑耗时。Why：文件时间不是可靠的重建计时。备选是从 mtime 推断，会产生错误数据。
5. 预览策略只在确认 Spark 公开接口与可复现问题后修改，不改 node_modules。Why：排序、抗锯齿与训练浮点问题需要区分，不能以滤除文件中的点代替显示修复。

## Risks / Trade-offs

- [引擎 CLI 与日志改变] -> 固定发布包，校验完整参数契约，使用真实运行验证导出、进度与取消。
- [显存、点数与细节取舍] -> 按质量/预算选择；保存实际参数；同素材中档完成训练后比较，明确验证边界。
- [跨时间匹配增加耗时] -> 有界候选对，复用已有特征，不做全量平方级匹配；记录实际耗时。
- [历史资产没有计时] -> 只读兼容既有字段，不从日期伪造，不批量改写旧模型。
- [剩余磁盘空间不足] -> 测试集中于独立临时工作区，限制同时常驻的训练副本；不清理真实用户数据。

## Migration Plan

新版本引擎与原 0.3.0 共存，安装失败不影响原目录；新版配方必须与新 CLI 同批应用。回退代码时可使用原依赖及原模型，现有资产无需重写。旧便携包按 runtime gate 要求换完整包；本次验证不改写已有 v2.0.0 ZIP 或标签。

## Open Questions

同素材测试视频已由用户提供；上游完成结果可只读检查。画质改进与预览移动稳定性的实测结果写入文档，不将单次测试概括为普遍保证。

## Validation outcome

同一源视频哈希核对一致；新中档流程在独立工作区完整成功，196/196 帧配准、SH3 PLY/SPZ、560316 点，总耗时 1013.859 秒。默认均衡显示保留抗锯齿，未定位到可支持全局更换排序的应用级错误；快速运动的瞬态闪烁不作为已彻底消除的问题。额外单图实跑在上游加载 checkpoint 时原生退出，单图计时持久化及编辑继承由回归验证。Linux/macOS 及新版完整便携包本次未做端到端发布验收。

按用户要求，对比审计明细保存在仓库外；不新增或修改公开的 0.6/0.7 对比文章。使用指南仅描述当前功能、计时语义和运行时兼容边界。

### Quality-first revalidation (2026-10-22)

用户提供的大侧向截图显示屏幕、键盘前方有大块半透明薄片及拉丝，前一轮的小偏转与耗时统计不足以支持质量验收。现已输出五个源相机、三个小偏转和 ±45°/±70° 对照；参考与新结果通过 50 个相同源帧对齐。旧结果没有保留训练相机，只能近似对齐，已明确限制。

完成延长训练、加强大高斯拆分、增加不透明度衰减及真实源像素 2560 四项独立训练实验；均未稳定解决侧向薄片，因此不采用这些实验参数作为默认。2560 改善部分正面细节，也不能代替漂浮问题验收。默认配方仍是待验收候选；时间缩短和点数变化不构成画质结论。

另外确认 Spark 默认打包源数据和中间累积会增加量化损失，尝试过 ExtSplats 与 accumExtSplats。真实 SDK 数据回归、lint、build 已通过，但基础点缓冲 16→32 字节/点存在内存代价，且此改动不能解决大片薄片。本轮浏览器安全检查因无法确认当前 URL 停止自动操作，未完成实际编辑、动画导出、LoD 和动态稳定性验收。用户决定暂缓后，此显示实验及配套动画判断改动已移出发布候选，补丁保存在仓库外，继续使用原显示管线。
