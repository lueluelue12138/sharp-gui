## Context

useViewer 暴露 Three 相机、OrbitControls 与 SparkRenderer，拥有常驻渲染循环。现有 HTML 分享是模型查看器，不是视频编码器。复用已安装 Three/Spark，不新增运行时依赖。

## Goals / Non-Goals

**Goals:** 手动关键帧、排序/替换/时长、连续播放与定位、项目 JSON 保存/载入、逐帧 WebM 下载，保持模型原始数据和方向。

**Non-Goals:** 音轨、时间轴模型变形、后端渲染队列、自动运镜、MP4 转码。

## Decisions

1. 记录相机 position/quaternion/target/fov。用户实测反馈生硬后，新增默认连续平滑运镜：时间加权 Hermite 位置/目标/镜头与四元数 Bezier 朝向，中间帧保持速度连续，首尾启停；另有标准缓入缓出、正弦、五次柔和停靠与匀速。Why：保留 roll，避免欧拉角跳变和逐点刹停。备选 lookAt 插值会丢失 roll；逐段 easing 继续保留用于定点停靠。连续路径可能略偏离折线，在 UI 明示并要求先预览。
2. WebCodecs VP9/VP8 + 小型 WebM 封装，固定时间戳逐帧等待 Spark 排序再编码。Why：不依赖便携包 FFmpeg，不因 GPU 慢而丢时间帧。备选 MediaRecorder 实时录屏可能掉帧；后端 PNG 上传扩大 API 与磁盘任务范围。
3. 导出期间独占现有渲染上下文，保存并恢复尺寸、相机、背景、控制、LoD 配置，暂禁输入与其它查看器操作；普通播放只接管相机。Why：避免第二份模型显存和额外下载。备选复制 renderer/mesh 会扩大显存使用。
4. 玻璃态面板复用 Button、Token 与 lucide 图标，中英同步。当前模型内保留草稿，跨会话通过显式 JSON 保存/载入，不写模型 sidecar。

## Risks / Trade-offs

- [编码兼容] -> 运行时检测安全上下文、编码器及配置；不支持时仍可编辑和预览。
- [大模型/4K 内存] -> 限制 100 帧位、120 秒、512 MiB 编码输出，队列背压，提供取消；失败保持源模型不变。
- [异步排序/输入串扰] -> 暂停正常循环渲染，等待已有排序完成，逐帧显式 update；取消、卸载、异常均恢复上下文。
- [分页模型不能保证完整细节] -> 外部分页 RAD 明确拒绝视频导出，提示切换完整 SPZ/PLY；普通完整模型导出关闭 LoD，恢复时还原原值。
- [画幅改变取景] -> 面板开启即锁定所选画幅并显示真实取景区域，保存关键帧和预览均使用该画幅。

## Migration Plan

无用户数据迁移。普通查看器仅新增可选相机接管接口，关闭面板恢复原行为；可回退源码与同提交 dist。
